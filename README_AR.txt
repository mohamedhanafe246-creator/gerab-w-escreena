جراب واسكرينة — إصدار أولي متصل بـ Cloudflare D1

الملفات مفكوكة وجاهزة داخل هذا المجلد:
- public/index.html : واجهة النظام
- src/worker.js : خادم API والصلاحيات
- schema.sql : الجداول
- wrangler.jsonc : إعدادات الربط والنشر

مهم: لا ترفع index.html وحده إلى Worker الحالي؛ النشر يتطلب رفع Worker والملفات الثابتة معاً، وإلا ستظل صفحة JSON القديمة.

قبل النشر:
1) تأكد أن قاعدة D1 اسمها gerab-w-escreena-db وأن معرفها في wrangler.jsonc يطابق القاعدة الفعلية.
2) نفذ schema.sql على قاعدة D1 مرة واحدة عبر D1 Console أو Wrangler.
3) ثبت Node.js LTS من الموقع الرسمي nodejs.org ثم افتح CMD جديد داخل هذا المجلد.
4) نفذ: npx wrangler login
5) نفذ: npx wrangler deploy
6) افتح رابط workers.dev؛ ستظهر شاشة إنشاء المدير أول مرة.
7) اختر كلمة مرور قوية (12 حرف على الأقل)، ولا تشاركها مع أحد.

اختبار أولي: أنشئ المدير، افتح الشهر ثم اليوم، أضف صنفاً، سجّل بيعه، تحقق من نقص المخزون. جرّب حساب عامل وتأكد من عدم وصوله لتقارير الشهر.

تنبيه: هذا إصدار أولي للاختبار قبل إدخال بيانات متجر حقيقية. يجب اختبار المعاملات المتزامنة، الاسترجاع، النسخ الاحتياطي، الأمان، والتعامل مع الأخطاء قبل الاستخدام التجاري. تعديل المبيعات والجرد حالياً ليسا معاملة ذرية كاملة؛ قد يحدث عدم اتساق عند تعطل الطلب بين تحديثين. لا تستخدمه كنظام محاسبي نهائي دون تحسين ذلك.
